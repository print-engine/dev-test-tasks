# WebSocket Notifications Client

This is a testing client for the WebSocket Notifications Service assessment.

## Live Demo

This client is hosted via GitHub Pages and can be accessed at:
`https://[your-github-username].github.io/dev-test-tasks/`

## Usage

1. Start your WebSocket server locally (default: `ws://localhost:8080/ws`)
2. Open this page in your browser
3. Click "Connect" to establish a WebSocket connection
4. Use the various controls to test your implementation

## Features

- **Connection Management**: Connect and disconnect from WebSocket server
- **Messaging**: Send broadcast and direct messages
- **Room Management**: Join and leave rooms, send room-scoped messages
- **Event Simulator**: Trigger various event types
- **Stress Testing**: Test with multiple concurrent connections
- **Message Display**: Real-time display of all messages

## Local Usage

You can also open `index.html` directly in your browser from your local filesystem.
